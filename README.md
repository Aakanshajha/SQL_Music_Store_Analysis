## 📌 Project Overview

The **Music Store Data Analysis** project focuses on analyzing an online music store database using SQL and PostgreSQL.

The main objective is to explore music store data, identify meaningful business insights, and understand customer purchasing behavior, sales performance, popular music genres, and artist trends.

By writing SQL queries, this project demonstrates how database analysis can help businesses make informed, data-driven decisions.

## 🎯 Project Objectives

- Analyze customer purchasing patterns.
- Identify top-performing artists and music genres.
- Explore sales and revenue-related information.
- Understand customer distribution across different cities and countries.
- Identify popular tracks and albums.
- Generate meaningful insights to support business decisions.

## 🔍 Key Analysis Areas

The project focuses on answering business-related questions through SQL:

1. **Customer Analysis:** Understanding customer behavior and identifying valuable customers.
2. **Sales Analysis:** Exploring revenue trends and sales performance.
3. **Genre Analysis:** Finding popular music genres.
4. **Artist Analysis:** Identifying artists with strong sales performance.
5. **Geographical Analysis:** Exploring customer locations and revenue distribution.
6. **Track Analysis:** Analyzing track details, durations, and popularity.

## 💡 Business Value & Insights

This analysis can help an online music store:

- Recognize popular genres and artists.

- Make better data-driven decisions.

## ⚙️ How to Run the Project

Follow these steps to explore the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Aakanshajha/SQL_Music_Store_Analysis.git
   ```

2. Open **pgAdmin 4**.

3. Create a new PostgreSQL database.

4. Open the SQL file in the Query Tool.

5. Execute the database creation and setup scripts in the required order.

6. Run the analysis queries to explore the music store database.
